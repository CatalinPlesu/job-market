# Job Market - GitHub Pages

This directory contains the static HTML/JavaScript site for browsing job listings, hosted on GitHub Pages.

## Architecture

### Frontend (Vue.js SPA)
- **Technology**: Vue.js 3 (loaded from CDN)
- **Structure**: Component-based architecture with separate files
- **Location**: `/pages/`

### API (Static JSON)
- **Location**: `/pages/api/jobs/`
- **Format**: Normalized JSON structure with lookup tables
- **Generated by**: `src/generate_html_page.py`

## Directory Structure

```
pages/
├── index.html              # Main HTML entry point
├── test.html              # API test page (for debugging)
├── js/
│   ├── app.js             # Main Vue app initialization
│   ├── components/
│   │   ├── job-list.js    # Job listing component

│   │   └── filters.js     # Filter/search component
│   └── services/

└── api/
    └── jobs/
        ├── pages-list.json    # Pagination metadata
        ├── page-1.json        # Jobs data (paginated)
        ├── page-2.json        # ...
        └── lookups.json       # Normalized lookup tables
```

## Features

### 1. Job Listings
- Paginated display (50 jobs per page)
- Card-based layout with key information
- Responsive design for mobile/desktop

### 2. Job Details
- **Structured Tab**: Clean display of job information
  - Compensation, requirements, location
  - Skills (technical and soft)
  - Responsibilities, benefits, languages
  - Contact information
- **Raw Data Tab**: Debug view with full JSON data

### 3. Duplicate Detection
Jobs with the same title and company are merged:
- Shows "Found on N sites" badge
- Lists all source URLs
- Prevents duplicate listings

### 4. Filters
- Search by job title or company name
- Filter by:
  - City
  - Work location (remote/hybrid/on-site)
  - Seniority level
  - Employment type

### 5. Normalized Data
Uses lookup tables to reduce data size:
- Common values stored once in `lookups.json`
- Jobs reference IDs instead of duplicating strings
- Efficient for large datasets

## Usage

### Generating the Site

Run from the main menu (option 9) or directly:

```bash
python -c "from src.generate_html_page import generate_html_page; generate_html_page()"
```

This will:
1. Read all jobs from `databases/data.db`
2. Deduplicate jobs (same title + company)
3. Generate paginated JSON files
4. Create lookup tables
5. Output to `pages/` directory

### Local Testing

```bash
cd pages
python -m http.server 8080
# Open http://localhost:8080 in browser
```

### GitHub Pages Deployment

1. Push the `pages/` directory to your repository
2. Enable GitHub Pages in repository settings
3. Set source to the branch containing `pages/`
4. Site will be available at: `https://{username}.github.io/{repo}/`

## API Structure

### pages-list.json
```json
{
  "total_jobs": 150,
  "total_pages": 3,
  "jobs_per_page": 50,
  "generated_at": "2026-01-01T10:00:00",
  "pages": [
    {
      "page": 1,
      "job_count": 50,
      "first_posting_date": "2026-01-01",
      "last_posting_date": "2025-12-20"
    }
  ]
}
```

### page-N.json
```json
{
  "jobs": [
    {
      "id": 1,
      "job_title": "Software Engineer",
      "company_name": "TechCorp",
      "site": "JobSite1",
      "sites": ["JobSite1", "JobSite2"],  // If duplicate
      "job_urls": [{"site": "JobSite1", "url": "..."}],
      "city_id": 1,
      "seniority_level_id": 3,
      "hard_skill_ids": [1, 5, 12],
      // ... normalized fields with IDs
    }
  ]
}
```

### lookups.json
```json
{
  "cities": {
    "1": "Chisinau",
    "2": "Balti"
  },
  "seniority_levels": {
    "1": "entry",
    "2": "junior",
    "3": "mid"
  },
  "hard_skills": {
    "1": "Python",
    "5": "JavaScript",
    "12": "Docker"
  }
  // ... all lookup tables
}
```

## Development

### Adding New Components

1. Create component file in `js/components/`
2. Export as ES6 module
3. Import in `app.js`
4. Register in Vue app

### Modifying Data Structure

1. Update `src/generate_html_page.py`
2. Regenerate JSON files
3. Update component templates to display new fields

## Notes

- API files (JSON) are in `.gitignore` - regenerate before deployment
- HTML/JS files are tracked in git
- Lookup tables reduce total data size significantly
- Pagination prevents loading too much data at once
