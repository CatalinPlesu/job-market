# Frontend Setup & Testing Guide

## Quick Start

### Option 1: Local Development Server

```bash
# Navigate to pages directory
cd pages

# Start Python HTTP server
python3 -m http.server 8080

# Or use Node.js http-server
npx http-server -p 8080

# Open browser
# http://localhost:8080
```

### Option 2: Direct File Access (Limited)

Due to CORS and module import restrictions, opening `index.html` directly in browser won't work. Always use a local server.

## CDN Dependencies

The app loads all dependencies from CDN (no build step required):

### Required CDNs
1. **DaisyUI + Tailwind CSS** - UI framework and styling
   ```html
   <link href="https://cdn.jsdelivr.net/npm/daisyui@4.12.14/dist/full.min.css" />
   <script src="https://cdn.tailwindcss.com"></script>
   ```

2. **Mithril.js** - JavaScript framework
   ```html
   <script src="https://unpkg.com/mithril@2.2.2/mithril.js"></script>
   ```

3. **Lodash** - Utility library for debouncing
   ```html
   <script src="https://cdn.jsdelivr.net/npm/lodash@4.17.21/lodash.min.js"></script>
   ```

### Troubleshooting CDN Access

If CDNs are blocked (corporate firewall, sandboxed environments):

1. **Check browser console** for blocked requests
2. **Disable ad blockers** or tracking protection temporarily
3. **Try alternative CDNs**:
   - jsDelivr: `https://cdn.jsdelivr.net/`
   - unpkg: `https://unpkg.com/`
   - cdnjs: `https://cdnjs.cloudflare.com/`

4. **Download libraries locally** (not recommended):
   ```bash
   # Download to pages/lib/
   wget https://unpkg.com/mithril@2.2.2/mithril.js
   # Update script tags in index.html
   ```

## Development Tips

### Hot Reload
Python's HTTP server doesn't auto-reload. Use browser refresh (Ctrl+R / Cmd+R).

For auto-reload during development:
```bash
# Install browser-sync
npm install -g browser-sync

# Run with auto-reload
cd pages
browser-sync start --server --files "**/*.html,**/*.js,**/*.css"
```

### Debugging
1. **Open browser console** (F12)
2. **Check Network tab** for failed requests
3. **Check Console tab** for JavaScript errors
4. **Use Mithril DevTools** (if available)

### Component Development
1. Edit component files in `js/components/`
2. Refresh browser to see changes
3. Check console for errors
4. Use `console.log()` for debugging

### State Management
State is managed in `main.js`:
- `state` object holds all app state
- `actions` object holds all state mutations
- Components receive state/actions as attrs
- Use `m.redraw()` to force re-render

## Deployment

### GitHub Pages

1. **Generate production data**:
   ```bash
   python -m src.generate_html_page
   ```

2. **Deploy to GitHub Pages**:
   ```bash
   # Push pages directory to gh-pages branch
   git subtree push --prefix pages origin gh-pages
   ```

3. **Configure GitHub Pages**:
   - Go to repository Settings → Pages
   - Source: `gh-pages` branch
   - Root directory: `/`

### Custom Domain

Update `CNAME` file in pages directory:
```
jobs.example.md
```

## Common Issues

### Issue: Blank page
**Cause**: CDN resources blocked or failed to load  
**Solution**: Check browser console, verify internet connection, try different CDNs

### Issue: "m is not defined"
**Cause**: Mithril.js didn't load  
**Solution**: Verify CDN is accessible, check script tag order in HTML

### Issue: Filters don't work
**Cause**: Mock API data missing  
**Solution**: Verify `api/` directory exists with proper JSON files

### Issue: CORS errors
**Cause**: Opening HTML file directly instead of using server  
**Solution**: Always use local HTTP server

### Issue: Module import errors
**Cause**: JavaScript modules require HTTP server  
**Solution**: Use `python3 -m http.server` or equivalent

## Performance Optimization

For large datasets (10,000+ jobs):

1. **Enable virtual scrolling** for job list
2. **Implement progressive loading** (load pages on demand)
3. **Cache API responses** in browser
4. **Optimize filter queries** with indexing
5. **Consider server-side filtering** for very large datasets
