## Аннотация

### Введение и актуальность

Современный рынок труда характеризуется высокой динамикой и большими объемами данных. Ежедневно тысячи вакансий публикуются на различных онлайн-платформах, что делает ручную обработку и анализ этих данных крайне неэффективными. Форматы представления информации о вакансиях значительно различаются между платформами, что усложняет их систематизацию и сравнительный анализ.

В Республике Молдова основными платформами для размещения вакансий являются:
- **Rabota.md** - крупнейшая платформа по трудоустройству
- **Jobber.md** - современная платформа с интерактивным интерфейсом
- **Delucru.md** - специализированная платформа для различных отраслей

Возникает острая необходимость в автоматизированной системе, способной собирать, обрабатывать и классифицировать вакансии, преобразуя неструктурированные текстовые данные в структурированный формат и представляя результаты в наглядной форме для анализа тенденций рынка труда.

### Цель и задачи исследования

**Цель данной работы** заключается в разработке комплексной системы автоматического анализа и классификации вакансий, размещаемых на различных онлайн-платформах. Система обеспечивает преобразование неструктурированных текстовых данных в структурированный формат, выявление ключевых характеристик вакансий (отрасль, должность, требования, уровень заработной платы и регион), а также визуализацию полученных результатов в удобной и наглядной форме.

**Основные задачи:**

   - Обзор существующих систем анализа вакансий

2. **Разработка системы сбора данных:**

   - Реализация двухэтапного процесса scraping (сбор URL-адресов и детальной информации)
   - Интеллектуальная оптимизация процесса сбора с ранней остановкой при обнаружении существующих вакансий
   - Обработка пагинации и различных форматов представления данных

   - Классификация вакансий по отраслям, должностям и требуемым компетенциям с использованием моделей искусственного интеллекта (LLM)
   - Нормализация данных и создание связей между различными сущностями
   - Извлечение структурированной информации: зарплаты, навыки, бенефиты, требования, сертификаты

4. **Разработка системы хранения:**

   - Создание дуальной архитектуры баз данных (сырые данные и обработанные данные)
   - Оптимизация запросов и индексация для быстрого доступа к данным

5. **Анализ и визуализация:**
   - Формирование визуальных отчётов (графики, диаграммы, HTML-страница)
   - Разработка модулей для анализа трендов навыков, зарплат, здоровья рынка
   - Создание интерактивного конструктора пользовательских аналитических запросов
   - Предоставление статистики и трендов о рынке труда и о профессиях в отдельности

6. **Тестирование и оценка:**

   - Проверка корректности извлечения структурированных данных

### Поставленная проблема

Современный рынок труда сталкивается с рядом существенных проблем:

- **Объем данных:** Ежедневно генерируются тысячи вакансий на различных онлайн-платформах, что делает ручную обработку таких данных неэффективной и трудоемкой.

- **Разнородность форматов:** Форматы представления информации на разных платформах значительно различаются, что усложняет их анализ, систематизацию и сравнение.

- **Неструктурированные данные:** Большинство описаний вакансий представлены в виде свободного текста без четкой структуры, что затрудняет автоматическую обработку.

- **Отсутствие централизованной аналитики:** Не существует единой системы, которая бы агрегировала данные со всех платформ и предоставляла комплексный анализ рынка труда.

- **Дублирование информации:** Одна и та же вакансия может быть размещена на нескольких платформах, что усложняет подсчет реальных предложений.

- **Динамичность данных:** Вакансии постоянно появляются и исчезают, требуется система отслеживания актуальности.

### Архитектура разработанной системы

Разработанная система имеет модульную архитектуру и состоит из следующих основных компонентов:

#### 1. Модуль сбора данных (Web Scraping)

**Двухэтапный процесс scraping:**

- **Stage 1 (Сбор списков вакансий):**
  - Навигация по страницам пагинации начиная с первой страницы
  - Извлечение URL-адресов вакансий со страниц списков
  - Интеллектуальная оптимизация: автоматическая остановка при обнаружении 100+ последовательных существующих вакансий
  - Обнаружение дубликатов страниц для предотвращения бесконечных циклов
  - Отслеживание статистики по количеству обработанных страниц для каждого сайта
  - Поддержка двух режимов: Smart Mode (с оптимизацией) и Full Scrape (полный сбор)

- **Stage 2 (Сбор детальной информации):**
  - Посещение каждого URL-адреса вакансии
  - Извлечение полного описания вакансии и всех деталей
  - Сохранение сырых данных (HTML/текст) в базу данных `scrape.db`
  - Отслеживание статуса загрузки (успех/ошибка)

- **Stage 3 (Верификация и обработка):**
  - Stage 3a: Повторная проверка активных вакансий для обнаружения удаленных
  - Stage 3b: Обработка новых вакансий с LLM (структурирование данных)
  - Stage 3c: Копирование баз данных в директорию frontend
  - Stage 3d: Автоматическая публикация в Git репозиторий (если настроено)

**Технологии:**
- Python с библиотеками `requests`, `aiohttp` для HTTP-запросов
- `BeautifulSoup4` для парсинга HTML
- Конфигурационные правила в JSON формате (`scraper_rules.json`)
- Параллельная обработка нескольких сайтов

#### 2. Модуль обработки с LLM

**Интеграция с большими языковыми моделями:**

- Использование OpenAI API (совместимых моделей) для извлечения структурированных данных
- Отправка описаний вакансий в LLM с специальным промптом для извлечения
- Парсинг JSON-ответов от LLM
- Валидация и очистка извлеченных данных

**Извлекаемые поля (более 30 полей):**
- Нормализованное название должности
- Категория отрасли и подкатегория
- Тип занятости (полная, частичная, контракт, стажировка)
- Диапазон зарплаты (минимум, максимум, валюта, период)
- Местоположение (город, регион, возможность удаленной работы)
- Требуемые навыки (технические и soft skills)
- Требуемый опыт работы (годы)
- Образование (уровень, специальности)
- Языки и уровни владения
- Бенефиты и преимущества
- Обязанности и требования
- Сертификаты и лицензии

**Обработка ошибок:**
- Retry-логика для неудачных запросов
- Логирование ошибок парсинга
- Откат к частичным данным при невозможности полной обработки

#### 3. Модуль базы данных

**Дуальная архитектура баз данных:**

- **scrape.db (Сырые данные):**
  - Таблица `jobs`: оригинальные публикации вакансий
  - Таблица `job_checks`: отслеживание статуса вакансий
  - Таблица `site_statistics`: метрики производительности scraping

- **data.db (Обработанные и нормализованные данные):**
  - Таблица `job_details`: извлеченная и структурированная информация о вакансиях
  - Более 50 справочных таблиц для нормализованных данных:
    - Города, регионы, страны
    - Компании и отрасли
    - Должности и категории
    - Навыки (технические и soft skills)
    - Языки и уровни владения
    - Бенефиты и преимущества
    - Сертификаты и лицензии
    - Образовательные программы
  - Отношения many-to-many для навыков, бенефитов, сертификаций

**Технологии:**
- SQLite для хранения данных
- SQLAlchemy ORM для работы с базой данных
- Полная нормализация с внешними ключами
- Автоматические backup-и (сохранение последних 3 дней)

#### 4. Модуль анализа и аналитики

**Временные анализы (Temporal Analysis):**
- **Skills Trends:** Тренды популярности навыков во времени
- **Salary Trends:** Изменение зарплатных предложений
- **Posting Trends:** Динамика публикации вакансий
- **Market Health:** Показатели здоровья рынка труда
- **Remote Trends:** Тенденции удаленной работы

**Статические анализы:**
- **Salary Analysis:** Распределение зарплат по должностям и отраслям
- **Skills Analysis:** Наиболее востребованные навыки
- **Companies Analysis:** Статистика по компаниям и работодателям
- **Employment Analysis:** Типы занятости и условия

**Генерация отчетов:**
- Ежедневные JSON/текстовые отчеты
- Статистика по каждому сайту
- Агрегированные показатели
- История изменений

#### 5. Веб-интерфейс (Frontend)

**Single Page Application (SPA):**

- **Технологический стек:**
  - Mithril.js framework (через CDN)
  - DaisyUI + Tailwind CSS для UI (через CDN)
  - Chart.js для визуализации данных (через CDN)
  - SQL.js для работы с SQLite в браузере
  - Клиентская маршрутизация (hash routing)

- **Основные функции:**
  - Минималистичные списки вакансий (стиль Hacker News)
  - Клиентская фильтрация по множественным полям с иерархической фильтрацией
  - Детальный просмотр вакансий с вкладками (обработанные/сырые данные)
  - Темная/светлая тема
  - Адаптивный дизайн для мобильных устройств

- **Конструктор пользовательских анализов:**
  - 15+ предопределенных аналитических запросов
  - Конструктор произвольных SQL-запросов с живой визуализацией
  - Множественные типы графиков (столбчатые, линейные, круговые, кольцевые)
  - Сохранение запросов в localStorage браузера
  - Документация структуры базы данных для пользователей

- **Визуализация данных:**
  - Интерактивные графики и диаграммы
  - Экспорт данных в различных форматах
  - Real-time обновление при изменении фильтров

#### 6. Система планирования и автоматизации

**Scheduler (Планировщик):**

- **Оптимизированное расписание:**
  - Stage 1 & 2: Каждый час (быстрые этапы с ранней остановкой)
  - Stage 3: Ежедневно в 00:00 (полный автономный workflow)
  
- **Функции автоматизации:**
  - Автоматическое резервное копирование перед каждым запуском
  - Логирование только ошибок (еженедельные лог-файлы)
  - Ежедневные отчеты со статистикой по каждому сайту
  - Полностью автономная работа без ручного вмешательства

- **Режимы отладки:**
  - `DEBUG_RUN_STAGE3_NOW=true`: Немедленный запуск Stage 3 вместо ожидания 00:00
  - `DEBUG_SKIP_SCRAPING=true`: Пропуск scraping и переход сразу к обработке LLM + deployment

#### 7. Система развертывания

**Автоматическое развертывание:**

- **Git Integration:**
  - Инициализация/обновление git репозитория в директории frontend
  - Коммит и push изменений в удаленный репозиторий
  - Поддержка GitHub Pages, Netlify и других платформ

- **Два подхода:**
  - **Fresh (по умолчанию):** Удаление истории .git и force push (компактный размер репозитория)
  - **Incremental:** Сохранение истории git с регулярными коммитами

- **Custom Database Server:**
  - Standalone сервер `db_server.py` (нулевые внешние зависимости)
  - Защищенный паролем endpoint для загрузки
  - Публичный endpoint для скачивания
  - Полная поддержка CORS для всех браузеров
  - Интеграция с Caddy reverse proxy для автоматического HTTPS
  - Валидация файлов (проверка формата SQLite)
  - Конфигурируемые лимиты размера файлов (по умолчанию 500MB)

### Интеллектуальные алгоритмы и оптимизации

#### Идентификация вакансий

**Логика отслеживания:**
- Вакансии идентифицируются по триплету (site, title, company)
- **Job Resurrection:** Если вакансия исчезает и появляется снова после порогового периода (по умолчанию 7 дней), она рассматривается как новая позиция
- Отслеживание множественных публикаций одной и той же позиции во времени
- Обратная совместимость с существующими базами данных

#### Оптимизация эффективности Stage 1

**Ранняя остановка:**
- Автоматическая остановка при обнаружении 100+ последовательных вакансий, уже существующих в базе данных
- Порог настраивается через параметр `stage1_consecutive_known_threshold`
- Значительное сокращение времени выполнения при регулярных запусках

**Обнаружение дубликатов страниц:**
- Остановка при обнаружении двух последовательных страниц с идентичными URL-адресами вакансий
- Предотвращение бесконечных циклов
- Защита от неправильной конфигурации пагинации

#### Статистика страниц

**Отслеживание производительности:**
- Запись среднего количества обработанных страниц для каждого сайта
- Таблица `site_statistics` в `scrape.db`
- Анализ эффективности scraping для различных источников

### Технологические инновации

#### 1. Standalone Database Server

**Уникальные особенности:**
- Написан с использованием ТОЛЬКО стандартной библиотеки Python
- Не требует установки pip-зависимостей
- Легкий HTTP-сервер на основе модуля `http.server`
- Работает на Python 3.6+
- Просто скопируйте и запустите

**Безопасность:**
- Защита паролем для endpoint-а загрузки
- Валидация файлов (проверка magic number SQLite)
- Ограничение типов файлов (только data.db и scrape.db)
- Настраиваемые лимиты размера файлов
- Поддержка HTTPS через Caddy

#### 2. Dual Database Architecture

**Преимущества разделения:**
- **Изоляция:** Сырые данные отделены от обработанных
- **Масштабируемость:** Независимое масштабирование каждой базы
- **Гибкость:** Возможность повторной обработки без повторного scraping
- **Оптимизация:** Различные схемы индексации для разных типов запросов

#### 3. LLM Integration

**Эффективное использование:**
- Промпты оптимизированы для извлечения структурированных данных
- Пакетная обработка для снижения затрат на API
- Кэширование результатов для избежания повторной обработки
- Обработка ошибок с retry-логикой

### Заключение

Разработанная система представляет собой комплексное решение для автоматического анализа рынка труда Республики Молдова. Система успешно решает поставленные задачи:

1. **Автоматизация сбора:** Эффективный scraping с 3 основных платформ с интеллектуальными оптимизациями
2. **Структурирование данных:** Использование LLM для извлечения 30+ структурированных полей из неструктурированных описаний
3. **Хранение и организация:** Нормализованная база данных с более чем 50 таблицами и правильными отношениями
4. **Анализ и визуализация:** Комплексная аналитика с интерактивными графиками и пользовательскими запросами
5. **Автоматизация:** Полностью автономная работа с планированием и резервным копированием
6. **Доступность:** Современный веб-интерфейс с адаптивным дизайном

Система демонстрирует высокую практическую ценность для различных групп пользователей: соискателей, работодателей, исследователей и государственных органов.
